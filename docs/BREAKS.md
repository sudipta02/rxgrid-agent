# Build Log: Rules That Broke

Each entry is a real failure seen during build or stress testing. Entries are added as they happen and are never back-filled or invented.

Format:

```
## YYYY-MM-DD: <rule ID> <short title>
- **What broke:** observed behaviour (prompt / run ID / evidence link)
- **Why:** root cause
- **Fix:** change made (commit)
- **Re-test:** result after the fix (n/5 runs)
```
